# AI Support — Paymenter Extension

Automatically replies to customer support tickets using an AI of your choice.  
Supports **OpenAI (ChatGPT)**, **Anthropic (Claude)**, **Google (Gemini)**, **Mistral AI**, and any **OpenAI-compatible** endpoint (e.g. OpenCode, local models via Ollama, etc.).

**Author:** Buster4126
**Support:** [Discord](https://discord.gg/nk4xp9HBaU)

---

## Features

- Automatically answers new support tickets using AI
- Configurable system prompt so the AI knows who it is and how to behave
- Hosting/company information field so the AI can give accurate answers
- Department filter — disable AI replies for specific departments (e.g. Billing)
- Human hand-off — once a staff member replies, the AI stays silent on that ticket
- Anti-loop protection — the AI never replies to its own messages
- Discord webhook notification when the AI cannot answer a ticket
- API key stored encrypted in the database
- Supports multiple AI providers out of the box

---

## Requirements

- Paymenter (latest version recommended)
- A valid API key from your chosen AI provider (**your own key, see disclaimer below**)
- A dedicated Paymenter staff user for the AI bot (e.g. "AI Support Bot")

---

## Installation

1. Download the `AISupport` folder and place it under:
   ```
   extensions/Others/AISupport/
   ```
2. Log in to your Paymenter admin panel.
3. Go to **Extensions → Others** and find **AI Support**.
4. Click **Install**, then **Enable**.
5. Configure the extension as described below.

---

## Configuration

### 1. Create a Bot User
Create a new Paymenter staff user that the AI will reply as (e.g. name: `AI Support Bot`, any email).  
Copy the numeric user ID — you will need it below.

### 2. Extension Settings

| Setting | Description |
|---------|-------------|
| **AI Provider** | Select your provider: OpenAI, Anthropic (Claude), Google (Gemini), Mistral AI, or Custom |
| **API Key** | Your personal API key from the provider (stored encrypted) |
| **Model** | The model name, e.g. `gpt-4o`, `claude-3-5-sonnet-20241022`, `gemini-2.5-flash`, `mistral-large-latest` |
| **Custom API Base URL** | Only needed for "Custom" provider, e.g. `https://api.opencode.ai/v1` |
| **Bot User ID** | The numeric ID of the bot staff user you created in step 1 |
| **System Prompt** | Instructions for the AI — who it is, your company name, tone, and rules |
| **Hosting / Company Info** | Server specs, plans, policies, FAQs — context the AI uses to answer tickets |
| **Allowed Departments** | Departments the AI is allowed to handle. Leave empty for all departments |
| **Discord Webhook URL** | Optional — receive a notification when the AI cannot answer a ticket |

### 3. Example System Prompt

```
You are a friendly and professional support agent for ExampleHost.
You help customers with questions about their hosting services.
Always be polite, concise, and accurate.
Do not make promises about refunds, uptime guarantees, or custom deals.
If you are unsure about something, escalate instead of guessing.
```

### 4. How the AI decides to escalate

If the AI cannot answer a question it will respond with the internal marker `[[ESCALATE]]`.  
The extension will then **not** post any reply to the ticket and instead send a Discord notification (if configured) so a human agent can follow up.

---

## How it works

```
Customer sends message
        │
        ▼
Was it sent by the bot user?          → YES → Ignore (anti-loop)
        │ NO
        ▼
Was it sent by a staff member?        → YES → Ignore
        │ NO
        ▼
Has any human staff already replied   → YES → Ignore (human hand-off)
to this ticket before?
        │ NO
        ▼
Is the department allowed?            → NO  → Ignore
        │ YES
        ▼
Call AI API with conversation history
        │
        ├── API error / no response   → Discord notification (if set)
        ├── AI returns [[ESCALATE]]   → Discord notification (if set)
        └── AI returns an answer      → Post reply as bot user
```
